- Write an SQL query to select the name of the 5 youngest applicants from the

- SOLUTION:
```mysql
select name from applicants where country = 'Czech Republic' order by age asc limit 5; 		
```


- Count the number of applicants from Hungary who are aged 35 and above.
- SOLUTION:
```mysql
select count(*) from applicants where country = 'Hungary' and age >= 35;		
```

- SOLUTION:
```mysql
select name from applicants where name like 'B%';					
```

- Determine the average age of applicants from each country.				
- SOLUTION:
```mysql
select country, avg(age) from applicants group by country;
```

First create a new database called Hierarchical. Open the SQL file 'families.sql' and execute it. This should generate a table called categories which are categories of news articles on a newspaper website.

Each row in this table contains a column called parent_category_id, which tells you which parent category any category belongs to (the All categories number 25 has no parent, and so sits at the top of the hierarchy).

Create a query that shows the full Category Path for each category ordered by the name of the category. 

Result should look like image hierarchy.png

Hint: You'll need to use 2 self-joins and a string function to solve this exercise. You'll also need to trap for nulls, for those occasions when a family doesn't have a parent.

------Solution------

Table looks like this:
INSERT INTO categories (category_id, name, 		parent_category_id)  VALUES 
			(1, 	    'Politics', 	21),
			(4, 	    'Natural world', 	23),
			(13,	    'Old', 	    	24),
			(9, 	    'Entertainment', 	22),	
			(13,        'Old', 		24),
			(22,	    'Cultural',		25),
			(25, 	    'All categories',   NULL);


We need to obtain this:
			Name		Path
			Politics	All Categories > Socio/Political > Politics
			Natural World	All Categories > Scientific/Technical > Natural World
			All Categories	All Categories

-------
Solution
--------
The hierarchy of the 2 self joins must be built from the child -> parent -> grandparent
the syntax will look like c3. name, ' >', c2.name ,' >' , c1.name, but only if the (grand)parents are not null
Therefore CONCAT + COALESCE(value-if-not-null, else-value)  -- coalesce considers whether the source of the value is null or not


SELECT c1.name AS Name, CONCAT(
COALESCE(CONCAT(c3.name, ' > '), ''), 
COALESCE(CONCAT(c2.name, ' > '), '' ), 
c1.name
) AS Path
FROM categories c1
LEFT JOIN categories C2
on c2.category_id = c1.parent_category_id
LEFT JOIN categories c3
ON c3.category_id = c2.parent_category_id
;

Considering the above Employees table, as well as the below Buildings table,
find the names of the buildings that hold no employees,
showing the first 3 records only(considering alphabetic building name order)


table Buildings

Building_name	Capacity
1e		24
1w		32
2e		16
2w		20

-------
Solution
--------
SELECT Buildings.Building_name, COUNT(Employees.Name) 
FROM Buildings LEFT JOIN Employees
ON Buildings.Building_name = Employees.Building
GROUP BY Buildings.Building_name
HAVING COUNT(Employees.Name) = 0
ORDER BY Buildings.Building_name
LIMIT 3;

Given the 2 tables below, 
For every match involving 'POL', show the id, date and the number of goals scored.

game
id	mdate		stadium				team1	team2
1001	8 June 2012	National Stadium, Warsaw	POL	GRE
1002	8 June 2012	Stadion Miejski (Wroclaw)	RUS	CZE
1003	12 June 2012	Stadion Miejski (Wroclaw)	GRE	CZE
1004	12 June 2012	National Stadium, Warsaw	POL	RUS



goal
matchid	teamid	player			gtime
1001	POL	Robert Lewandowski	17
1001	GRE	Dimitris Salpingidis	51
1002	RUS	Alan Dzagoev		15
1002	RUS	Roman Pavlyuchenko	82


-------
Solution
--------
SELECT game.id, game.mdate, COUNT(goal.matchid) AS goals_scored
FROM game JOIN goal
ON game.id = goal.matchid
WHERE game.team1 LIKE 'POL' OR game.team2 LIKE 'POL' 		-- also game.team1 = 'POL' is ok
GROUP BY game.id, game.mdate;					-- SQL requires to list all non-aggregate columns in GROUP BY if an aggregate column(COUNT here) is used previously

Create a new table named Database with the following columns:
– Name A string (text) describing the name of the database, cannot be null
– Version A number (floating point) of the latest version of this database, by default 1.0
– Download_count An integer count of the number of times this database was downloaded, cannot be negative

-------
Solution
--------
CREATE TABLE IF NOT EXISTS MDatabase(		-- Database is a reserved SQL keyword, thus cannot be used for naming a DB
Name VARCHAR(255) NOT NULL,
Version FLOAT DEFAULT 1.0,
Download_count INTEGER CHECK (Download_count >=0)
);
