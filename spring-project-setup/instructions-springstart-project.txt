Create our first Spring Boot Application
•	Create a new project with Spring Initializr
•	Use following settings:
o	Name: springstart
o	Language: java
o	Type: Gradle-Groovy
o	Group: com.greenfoxacademy
o	Artifact: springstart
o	Package Name: com.greenfoxacademy.springstart
o	JDK: 11 (or the version you use)
o	Java: 11 - it should match your JDK version
o	Packaging: Jar
 see image spring-start-05.jpg in the same folder as this file
o	Spring Boot version: 2.7.x (because I used JDK 11 earlier)
	Spring Boot above version 3.0 requires JDK 17
o	Selected Dependencies:
	Developer tools -> Spring Boot DevTools
	Web -> Spring Web
	Template Engines -> Thymeleaf
  see image spring-start-06.jpg in the same folder as this file
•	Create Project
•	Open build.gradle file and if for any reason you are missing the dependencies, you can enter them in:
•	dependencies {
•	  implementation 'org.springframework.boot:spring-boot-starter-thymeleaf'
•	  implementation 'org.springframework.boot:spring-boot-starter-web'
•	  developmentOnly 'org.springframework.boot:spring-boot-devtools'
•	  testImplementation 'org.springframework.boot:spring-boot-starter-test'
} see image spring-start-06.jpg in the same folder as this file
Open terminal and start Spring boot app with ./gradlew bootRun or gradlew bootRun command   
see image spring-start-07.jpg in the same folder as this file
Open localhost:8080 in your browser. You should get the "Whitelabel Error Page". This means your application is running.

Hello World Web App
•	Lets create another controller "HelloWebController" to controllers package.
•	Add greeting method like:
•	@RequestMapping("/web/greeting")
•	public String greeting(Model model) {
•	    model.addAttribute("name", " World");
•	    return "greeting";
}
•	Add following HTML template file to "resources/templates/greeting.html"
•	<!DOCTYPE html>
•	<html xmlns:th="http://www.thymeleaf.org">
•	  <head>
•	    <title>Getting Started: Serving Web Content</title>
•	    <meta http-equiv="Content-Type" content="text/html; charset=UTF-8" />
•	  </head>
•	  <body>
•	    <p th:text="'Hello, ' + ${name} + '!'" />
•	  </body>
</html>
•	Recompile app
•	Open http://localhost:8080/web/greeting in your web browser
•	Your output should look like:
•	Hello, World! (It is a web page.)

Optional exercise (FizzBuzzWoof)
This exercise is a variation of the classic FizzBuzz.
•	For this exercise you could use your previous counter task.
•	Rules of the FizzBuzzWoof :
Write a program that prints out numbers. But for multiples of three print “Fizz” instead of the number, for multiples of five print “Buzz” and for the multiples of seven print “Woof”. For numbers which are multiples of both numbers use two keywords and for numbers which are multiples of the three numbers use three keywords.
•	If one keyword is printed out, use 24px sized font.
•	If two keyword is printed out, use 48px sized font.
•	If three keyword is printed out, use 72px sized font.
•	Example when the site was loaded 3 times, your output should look like:
Hello! This site was loaded Fizz times since last server start.
