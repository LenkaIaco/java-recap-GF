Spring MVC
Receives HTTP request via its DispatcherServlet, which delegates it for parsing( to: handler mapping find controller, handler adapter invoke controller, DataBinder binds form fields/query parameters to java objects, http message converter (@RequestBody) convert JSON/XML into java objects): URL parameters, form fields, JSON... converting into java objects(via @ModelAttribute, converters, data binding) and routing it to the appropriate controller + endpoint method.

Calls controller method
Prepares the model

1. Servlet Container - Dispatcher Servlet communication
HTTP Request arrives at Servlet container implementation, and is being handed to DispatcherServlet(a coordinating class, design pattern FrontController, because centralizes http request handling in in web applications, it extends java's HTTPServlet and is similar to Mediator from behavioral design patterns as it coordinates nany other components), which locates the correct endpoint.

2. Dispatcher Servlet request rooting and conversion management
Data from http request arrives at the endpoint method.
DataBinder and http message converter convert it to java objects(method parameters @ModelAttribute, @PathVariable, @RequestParam and method response @ResponseBody)
And the endpoint processes the input with some application logic(saving into database, applying filters, verifications...)


3.Dispatcher servlet - View Resolver - Thymeleaf communication
Calls ViewResolver to locate the correct HTML template
Dispatcher servlet hands the template and all data to Thymeleaf for HTML rendering

4.Thymeleaf 
	Takes model attributes(Java objects) from Model, if any 
	Inserts them into the HTML template (along with css, javascript)
	(one-direction only: Objects -> HTML, not vice versa)
	Produces final HTML


5. Dispatcher Servlet - Servlet Container communication
DispatcherServlet writes the final HTML from Thymeleaf to the HTTP response(response is further coordinated by Jakarta Servlet implementation, not Spring MVC)
And then hands it to the Servlet Container for sending it out via HTTP
